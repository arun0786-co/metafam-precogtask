# Knowledge Graph Analysis and Link Prediction

This project explores a genealogical knowledge graph (MetaFam dataset)
and implements rule mining and link prediction models.

## Tasks Completed
- Graph structure analysis
- Community detection
- Rule mining (Horn clauses, inverse rules, multi-hop rules)
- TransE implementation (from scratch)
- R-GCN implementation (from scratch)
- Filtered evaluation (MRR, Hits@1, Hits@10)

## Models
- TransE (embedding-based)
- R-GCN (graph neural network)

## Results

### TransE
MRR: 0.414  
Hits@1: 0.189  
Hits@10: 0.903  

### R-GCN
MRR: 0.651  
Hits@1: 0.449  
Hits@10: 0.991
